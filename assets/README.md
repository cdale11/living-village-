# Original cover art

`cover.png` is the Living Village cover illustration, created for this project
with OpenAI image generation on 2026-10-12. No external game art, trademarks or
stock assets were supplied. Distributed under this project's MIT license.

The 600x800 PNG is frontend box art, not a screenshot of the game. Gameplay art
remains original procedural pixel graphics drawn directly with SDL2. No image
codec or network service is required at runtime.

Packaging places it at `ports/livingvillage/images/cover.png`; see
[Ports artwork registration](../docs/port-art.md).
